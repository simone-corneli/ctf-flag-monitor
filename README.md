# CTF Flag Monitor

A Python-based network traffic analyzer for CTF
flag observability, developed using Scapy.

## Overview

This project aims to develop a network monitoring tool
capable of identifying and tracking flags transmitted
during Attack/Defense CTF competitions.

The tool will analyze network traffic to detect flag
in/out events and provide useful information for
network observability and anomaly detection.

## Objectives

- Network packet sniffing and analysis.
- Network layer inspection.
- TCP session analysis and stream reconstruction.
- Flag detection through regular expressions.
- Flag event logging.
- Network traffic metrics and anomaly detection.

## Technologies

- Python
- Scapy
- TCP/IP
- Wireshark
- Git

## Project Structure

- `experiments/`: Scapy learning experiments.
- `src/`: Main application source code.
- `docs/`: Technical documentation.
- `captures/`: Network capture documentation.
- `tests/`: Tests.
